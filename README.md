# Royal_GP
Developed as a complete mechatronics graduation project, this repository contains the hardware and software architecture for an autonomous ground robot designed to eliminate toxic weeds in precision agriculture applications, specifically for Royal Herbs fields. Built from the ground up, the system integrates an NVIDIA Jetson-powered computer vision pipeline using YOLO to successfully identify harmful plants among crops in real-time. Upon detection, the robot employs a custom targeted laser mechanism to actively neutralize the weeds without the use of chemical herbicides. By combining ROS 2-based navigation, sensor fusion, and active laser eradication, this project provides a fully integrated, chemical-free crop care solution.
