# Royal_GP

Developed as a complete mechatronics graduation project, this comprehensive repository contains all engineering assets for an autonomous ground robot designed to eliminate toxic weeds in Royal Herbs fields without the use of chemical herbicides. Built entirely from the ground up, the repository hosts the project's complete mechanical CAD models, custom hardware electronics, and the high-level ROS 2 software architecture. The system integrates an NVIDIA Jetson-powered YOLO computer vision pipeline to identify harmful plants in real-time, coupled with a ROS 2-based navigation and sensor fusion stack. Upon detection, the robot employs a custom targeted laser mechanism to actively neutralize weeds, providing a fully integrated, open-source solution for precision crop care.
